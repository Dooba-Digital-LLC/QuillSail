# QuillSail documentation

QuillSail is open-source blog and newsletter software for publications written by their readers. Members submit their writing, editors review it, and the publication goes out on the web and by email from a server you control.

These guides cover everything from trying QuillSail on your own computer to running it for thousands of readers. They're the same files you'll find in the repository's `docs/` folder, so they always describe the code next to them.

## Start here

- **New to QuillSail?** Read [how QuillSail works](introduction.md) for the main ideas: publications, groups, the editorial workflow and newsletter issues.
- **Want to try it?** The [quickstart](quickstart.md) takes you from download to a first published post and a test issue in about fifteen minutes.
- **Ready to install?** [Ways to install](install.md) compares the desktop app, Docker Compose and the Python package.

## Getting help

QuillSail is beta software maintained on [GitHub](https://github.com/DoobaDigital/QuillSail). Ask questions and report problems in its [issues](https://github.com/DoobaDigital/QuillSail/issues). Report security problems privately, as described in the [security policy](../SECURITY.md). Never post passwords, subscriber lists or configuration files in a public issue.
